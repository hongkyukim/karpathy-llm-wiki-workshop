# Prompt — Answer from the maintained wiki

Use the Obsidian LLM Wiki as compiled knowledge, not as a bag of chunks.

Steps:
1. Read `index.md`.
2. Search pages for the user's key terms.
3. Read relevant entity/concept/comparison pages.
4. Synthesize an answer using wiki links as citations, e.g. `[[nanoGPT]]`.
5. If the answer is a reusable synthesis, file it under `queries/` and update `index.md` and `log.md`.

Do not answer solely from raw GitHub captures unless no curated page exists yet.
